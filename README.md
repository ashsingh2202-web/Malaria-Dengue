## 📌 Project Overview

This project presents a spatial epidemiologic analysis of malaria and dengue transmission hotspots using large-scale field survey data collected across multiple study regions in India. The objective was to identify geographic risk factors, map disease burden at the village level, and generate evidence to support targeted vector control strategies and public health intervention planning.

Over 100 field surveys were conducted to identify high-risk communities, with spatial analysis used to map disease distribution and evaluate environmental predictors of transmission.

## 📊 Methods

### Data Collection

Field surveys were conducted across multiple districts using standardized epidemiologic questionnaires. Village-level information included:

* Confirmed malaria case counts
* Confirmed dengue case counts
* Population denominators
* Rainfall indicators
* Temperature measurements
* Stagnant water assessments
* Geographic coordinates

### Analytic Pipeline

| Step                    | Method                                        | Tool |
| ----------------------- | --------------------------------------------- | ---- |
| Data Cleaning           | Variable standardization and rate calculation | SPSS |
| Attack Rate Calculation | Cases per 1,000 population                    | SPSS |
| Risk Stratification     | Four-tier risk classification                 | SPSS |
| Spatial Mapping         | Village-level hotspot mapping                 | QGIS |
| Environmental Analysis  | Correlation, t-tests, ANOVA                   | SPSS |
| Regression Modeling     | Linear and Poisson regression                 | SPSS |

---

## 🔍 Key Findings

* Malaria hotspots clustered in villages with high stagnant water prevalence following peak monsoon periods.
* Dengue burden was concentrated in urban-adjacent communities with higher average temperatures.
* Rainfall demonstrated a significant positive association with malaria incidence.
* Villages with stagnant water sources experienced significantly higher attack rates.
* Environmental predictors including rainfall, temperature, and stagnant water were independently associated with disease incidence.
* High-risk village profiles were identified for targeted intervention planning.
